# Adventofcode

This project is a collection of my solutions to [Adventofcode](https://adventofcode.com/) which are christmas themed coding puzzles.

## Requirements

Python 3

Install the python requirements :

```python
pip install -r requirements.txt
```

## Running the scripts

Run the following for the example data provided in the puzzle description.

```bash
python puzzle.py
```

Run the following for my personal puzzle input.

```bash
python puzzle.py input
```
